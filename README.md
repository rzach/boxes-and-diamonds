# Boxes and Diamonds

![Book Cover](https://bd.openlogicproject.org/bd.png)

A textbook for modal and other intensional logics based on the Open
Logic Project. It covers normal modal logics, relational semantics, 
axiomatic and tableaux proof systems, intuitionistic logic, and 
counterfactual conditionals.

This repository is retired. The code has moved to the main [OpenLogic](https://github.com/OpenLogicProject/OpenLogic) repository and can be found in `/textbooks/`. PDFs continue to be available on the [builds site](https://bd.openlogicproject.org/).
